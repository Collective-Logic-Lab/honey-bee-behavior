# NOTE

The current state of this branch is ready for migration of notebook files into the `notebooks/` file. The `notebooks/AnalysisSP25.ipynb` is an example of this migration.

Other notebooks are intentionally left in the root for discussion and processing. Note that some notebooks may have hardcoded paths and be obsolete.

A config utility (in utils/) is provided to reduce the boilerplate necessary to run the notebooks from arbitrary locations in the project folder.
